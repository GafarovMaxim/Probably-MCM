[b]Технические характеристики:[/b]
[list]
[*] [b]Точки входа в интерфейс:[/b] Меню паузы ([b]Esc[/b] ➔ «MCM-меню»), Главное меню (под кнопкой «Авторы»), глобальный хоткей (по умолчанию [b]F10[/b]).
[*] [b]Захват ввода (KeyBind):[/b] Диалоговое окно перехвата клавиш с поддержкой одиночных клавиш и модификаторов ([b]Ctrl[/b], [b]Alt[/b], [b]Shift[/b] + клавиша). Очистка значения клавишей [b]Delete[/b], отмена через [b]Esc[/b].
[*] [b]Поддерживаемые опции:[/b]
  [list]
  [*] Логические переключатели (bool)
  [*] Ползунки диапазонов (min, max, step, float/int)
  [*] Поля точного ввода целых и вещественных чисел с валидацией границ
  [*] Выпадающие списки (string[])
  [*] Текстовые поля ввода
  [*] Кнопки вызова действий (Action)
  [/list]
[*] [b]Режимы интеграции:[/b]
  [list]
  [*] [b]Zero-Dependency:[/b] Автоматическое распознавание стандартных ванильных [i]ModConfig[/i] записей без добавления внешних зависимостей.
  [*] [b]Fluent API:[/b] Прямое API через [i]ProbablyMCM.API.ModSettings[/i] с поддержкой секций, тултипов, динамической локализации [i]Func<string>[/i] и коллбэков [i]onChanged[/i].
  [/list]
[*] [b]Сохранение данных:[/b] Мгновенная сериализация в [i]ModConfigs/<ModId>.json[/i]. Поддержка полного сброса параметров к значениям автора.
[*] [b]Локализация:[/b] Встроенная поддержка 9 языков игры (RU, EN, ZH, DE, JA, FR, ES, PL).
[/list]
